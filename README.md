## 历史版本差异

- v1.0.0～v1.0.1 支持批量料号；v1.0.2 起限制为单料号转换。
- v1.0.3 的 PAD 前缀取源封装类型；v1.0.4 起与实际生成的封装名称一致。
- v1.0.5 的 Logo 清理仅支持已验证的完整独立标识组，不应描述为支持所有模型或可去除与本体合并的标识。
