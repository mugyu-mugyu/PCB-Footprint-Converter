# PCB Footprint Converter

输入立创商城料号，自动下载对应的嘉立创EDA/EasyEDA 标准版封装与可用的 STEP 模型，并调用本机 **Cadence Allegro 17.4** 生成原生封装库。

## 主要功能

- 输入单个立创料号，例如 `C76930`，或包含 C 料号的立创商城商品链接，自动下载并转换。
- 生成 Allegro 原生 `.dra`、`.psm`、`.pad`，特殊多边形焊盘按需生成 `.ssm`。
- 下载可用的 STEP 模型，自动清理可识别的标准文字与云图，再绑定到封装；支持模型偏移和旋转微调。
- 支持自定义封装名，PAD 前缀与实际封装名称一致，同规格引脚共用焊盘文件。
- 成功后自动清理中间文件；可关闭清理选项保留完整资料，失败或取消时保留诊断文件。
- 提供封装俯视预览、状态日志、取消和打开输出目录功能；每次转换使用独立子目录。
- 提供中文安装向导与卸载程序，内置转换引擎，无需额外安装 Python 或 FreeCAD。

## 运行要求

- Windows 10/11 64 位；实际验证环境为 Windows 11。
- 本机已安装且能正常启动 Cadence Allegro 17.4，需要可用的运行许可；实际验证版本为 17.4 S039。
- 下载时需要联网，且源接口存在对应的 EasyEDA 标准版封装或 STEP 模型。

安装包不包含 Cadence 软件。仅有专业版工程或源库缺少对应数据时，无法保证自动转换。

## 安装与使用

1. 在本仓库的 **Releases** 页面下载 `LCSC2Allegro174_Setup_1.0.6.exe`，按中文向导安装。默认按当前用户安装，无需管理员权限。
2. 从桌面或开始菜单启动 **PCB Footprint Converter**。
3. 输入一个立创料号。**一次只能转换一个料号**，不支持批量输入。
4. 确认 Allegro 程序路径，例如 `C:\Cadence\SPB_17.4\tools\bin\allegro.exe`。
5. 选择输出目录。默认保存到程序安装目录的 `Library` 子目录。
6. 如需自己命名，勾选“自定义封装名”，填写名称，例如 `C0201`。默认未勾选时使用程序生成的名称。
7. 按需设置“成功后清理中间文件”和“下载并绑定 STEP 3D 模型”，点击“开始下载并转换”。完成后打开输出目录。

程序会调用本机 Allegro 生成库文件，并核验引脚数量、位置、旋转、孔槽及电镀属性。主界面预览为封装俯视图；模型方向和高度需在 Allegro 的 3D 视图中检查。

## 输出文件与命名

默认成功输出保留以下库文件：

| 文件 | 用途 |
| --- | --- |
| `.dra` | 可继续编辑的 Allegro 封装图纸 |
| `.psm` | 可用于 PCB 的 package symbol |
| `.pad` | 封装引用的焊盘 |
| `.step` | 3D 模型本体，下载成功且启用 3D 时保留 |
| `.ssm` | 特殊多边形焊盘依赖的自定义形状，存在时必须保留 |

“成功后清理中间文件”默认开启，成功后清理脚本、日志、JSON 与 STEP 缓存。关闭该选项可保留完整转换资料；失败或取消时保留诊断文件。

自定义封装名允许英文字母、数字和下划线，最多 31 个字符，不接受 Windows 保留名称。勾选后必须填写名称；未勾选时不会使用输入框中遗留的自定义内容。

PAD 命名规则为：

```text
封装名称_pad_x.pad
```

前缀与实际生成的 DRA/PSM 名称一致。`x` 是不同焊盘规格的编号，从 1 开始，按源封装中首次出现的顺序排列；文件数量等于焊盘规格种类数，而非引脚数量。规格比较包含形状、尺寸、所在层、孔径、槽孔、电镀、阻焊及钢网扩展量。

例如 C76930 自定义名称为 `C0201`，两个同规格引脚共用一个 PAD：

```text
C0201.dra
C0201.psm
C0201_pad_1.pad
C0201.step
```

## 在 Allegro 中使用

打开 **Setup → User Preferences → Paths → Library**，把本次生成的子目录加入以下路径，并保留原有库路径：

| 设置 | 对应文件 |
| --- | --- |
| `psmpath` | `.psm`、`.ssm` |
| `padpath` | `.pad` |
| `steppath` | `.step` |

打开对应 `.dra` 可继续编辑；在设计中为器件分配实际生成的 package symbol 名称即可使用 `.psm`。已有 PCB 使用旧封装时，需要更新对应封装才能显示新版库和模型。

## 3D 模型与标识清理

勾选“下载并绑定 STEP 3D 模型”后，程序在下载与绑定之间自动清理已识别的完整 LCEDA / EasyEDA 两行文字与云图组合：

- **独立实体标识**：去除完整的 12 个文字实体与 1 个云图实体。
- **平面外凸浮雕**：识别与本体合并的完整标识组，移除浮雕并恢复承载平面，保留其他器件几何。

当前仅支持已验证的标准组合。其他字样、不完整标识、凹刻及非平面标识尚不支持自动清理；无法匹配时保留原模型，并在日志中显示结果。

**绑定后仍需保留 STEP 文件。** STEP 是模型本体，不能把它当作中间文件删除。源库没有可用 STEP 时，程序继续生成封装，并明确显示未包含 3D；不需要 3D 时可取消下载选项。

如果双击 STEP 启动了 FreeCAD 卸载程序，这是 Windows 文件关联问题。可从 FreeCAD 的“文件 → 打开”读取 STEP，并在 Windows 默认应用设置中将 `.step` 关联到 `FreeCAD.exe`。

## 升级与卸载

直接运行新版安装包可以覆盖安装。v1.0.5 → v1.0.6 已完成测试，已有设置和封装库保留；重复安装与卸载流程也已检查。

升级后需要重新转换料号才能得到清理后的模型，已有生成文件不会自动修改。

可通过 Windows“已安装的应用”、开始菜单的卸载入口或安装目录中的 `unins000.exe` 卸载。卸载删除程序文件与快捷方式，保留已生成的封装和模型库。

## 已知限制

- 当前面向 Allegro 17.4；未验证其他主版本或全部 17.4 补丁版本。
- 读取公开接口中的标准版封装，不直接导入专业版 `.epro` / `.elibz` 工程。
- 非圆椭圆焊盘、带自动扩展的多边形焊盘、复合区域内孔、Bézier 曲线、多个 3D 实例、内层电气图元及非 ASCII 文字等情况可能停止转换，并保留诊断资料。
- 源模型的非默认缩放不在自动校验范围内。通孔内层铜盘沿用外层尺寸，未自动补全负片平面的热焊盘与反焊盘。
- 下载依赖源接口和网络可用性；无法保证全部料号都有可转换的封装与 STEP。

生成后请按器件数据手册核对焊盘尺寸、引脚顺序、孔槽、阻焊、钢网及 3D 对齐。自动引脚核验不等于完整制造验证。

## 命令行

在安装目录中使用 PowerShell，可调用同一个程序转换单个料号：

```powershell
.\LCSC2Allegro174.exe --convert C76930 --name C0201 --output "D:\PCB_Library"
```

可用 `--allegro` 指定 Allegro 路径，`--no-3d` 关闭 3D 下载，`--keep-all` 保留完整转换资料。默认开启成功后清理和 3D 下载。成功返回代码 0；失败或取消返回代码 1。
